# learning
Repository untuk belajar terkait bidang Artificial Intelligence dan Internet of Things

## Status konten dan validasi

Pembaruan materi, ilustrasi, contoh kode, dan lab interaktif dalam repository ini mencakup **AI-generated content** (konten yang dibuat atau disunting dengan bantuan AI). Konten tersebut **perlu divalidasi ulang oleh maintainer atau pengajar** sebelum dijadikan acuan pembelajaran atau diterapkan pada perangkat nyata.

Validasi mencakup ketepatan konsep dan referensi, hasil perhitungan simulator, kompatibilitas kode dengan versi dependensi, serta wiring dan karakteristik board. Build situs dan pemeriksaan interaksi tidak menggantikan review substansi, eksekusi seluruh contoh, atau pengujian hardware.
