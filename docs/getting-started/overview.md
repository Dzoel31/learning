# Getting Started

Jika memakai ESP32, ikuti [instalasi Arduino IDE](arduino-ide.md). Setelah board muncul di menu pemilihan port, lanjutkan ke [latihan membaca DHT11](../hands-on/iot-hands-on.md#rangkaian-pemantau-suhu-dan-kelembapan).

Jika belum punya perangkat, mulai dari [Backend Mini](../hands-on/backend-mini.md) dan [IoT Simulator Mini](../hands-on/iot-simulator-mini.md). Hasil pertama yang dicari adalah respons dari server untuk satu kiriman contoh.
